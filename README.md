# React Components

One Vite + React website for the Week 9 practice. It contains the course introduction, component composition, state demos, E|C Student List, and the three sets of JSX solutions.

## Run locally

```sh
npm ci
npm run dev
```

Use `npm run build` to generate the production site. On Vercel select the Vite framework preset. Vite writes the production site to `dist`.
